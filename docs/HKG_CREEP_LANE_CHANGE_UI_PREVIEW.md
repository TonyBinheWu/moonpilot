# HKG 超低速變換車道：介面原型

## 本分支的實際功能

「轉向 → 自訂變換車道」頁新增「HKG 超低速變換車道（介面預覽）」開關。
此開關固定為關閉且不可操作，沒有參數鍵、寫入回呼或控制器連線。
可點選標題閱讀說明；相容性狀態沿用 `supports_low_speed_torque`。
未知車型、不相容車型及相容 HKG 車型皆不會啟用此原型。

這是介面原型，不是可用來上路測試新增自動變換車道或 400 轉向指令的版本。
繼承自基底分支的實驗功能不因本原型而取得新的驗證。

## 已確認的需求（尚未實作）

- 適用範圍沿用現有相容 HKG CAN-FD 扭力控制平台判斷，不擴展至其他品牌或不相容 HKG 平台。
- 預計使用範圍為 0–5 km/h。
- 只有系統實際執行自動變換車道時，才考慮額外低速扭力。
- 單純開方向燈、等待變換、一般轉彎或變換結束時，不授權此額外扭力。
- 模型辨識結果與前車距離為使用者指定的候選判斷依據。
- 400 為待驗證的 CAN 轉向指令上限，不是 Nm、保證輸出值或已驗證的安全上限。

使用者觀察目前模型跟車約保留一個車長；此敘述尚未以特定模型與行車紀錄驗證，不作為固定放行距離。
直行跟車間距與轉向時的車身淨空須分別檢查。

模型與前車距離不能單獨證明可安全切入；還需驗證車身掃掠範圍、側後方車流及感測資料的有效性。
目前未定義任何可授權實車變換的距離門檻，也沒有將感測不到目標解讀為安全。

## 未變更的控制邊界

此變更沒有修改自動變換車道狀態機、最低速度、轉向上限、Panda safety、
opendbc 子模組提交、模型輸出、煞車或駕駛介入邏輯。
新開關與既有 `HkgLowSpeedTorque` 開關互相獨立；不讀寫或切換該設定。

## 驗證與限制

- 已檢查新增 Python 程式的語法及差異空白。
- 已檢查新增繁體中文翻譯與程式訊息一致。
- 本環境缺少完整 sunnypilot UI 執行依賴，未完成裝置畫面、觸控或整套系統編譯驗證。
- 未進行實車、EPS、CAN 回放、碰撞判斷或道路測試；沒有宣稱控制效果。
