# OSM 路線與模型轉彎意圖

導航頁新增 **Use OpenStreetMap routes (OSRM)**，使用 OSRM 根據 OSM 路網規劃選定目的地的路線。保留 Mapbox 作為另一個路線來源。無 Mapbox 權杖時可以輸入「緯度, 經度」並確認目的地；地址搜尋仍需要使用者自己的 Mapbox 公開權杖。

預設 `https://router.project-osrm.org` 是線上的示範服務，沒有離線地圖或可用性保證。日常使用應設定自己的 HTTPS OSRM 伺服器。路線查詢會向所選伺服器傳送目前位置與目的地；UI 會說明此行為。實作依據 [OSRM Route API](https://project-osrm.org/docs/v5.24.0/api/#route-service)，OSM 資料標示貢獻者來源。

## 模型實際收到的內容

兩種模型執行器都沿用既有的 turn-desire 輸入。接近一般左轉或右轉，且駕駛確認路況並向轉彎方向輕推方向盤後，才會傳入既有的左／右轉意圖。

這**不是把 OSM 原始資料或 `nav_features` 接進大模型**。目前的模型權重沒有相容、已訓練的路線特徵介面；不以任意向量、假資料或地圖彎曲度冒充訓練輸入。路線不會判斷號誌、路權、障礙物或路口是否可安全通過，也不直接產生轉向／加速命令。

## 啟用與取消條件

預設關閉「Driver-confirmed navigation turns」。需先關閉 MADS、Lane Turn Desire 與 Pause Lateral Control with Blinker，並在停車狀態調整設定。轉彎提示與模型執行器採用相同的功能相斥條件。

只有新鮮、成功比對目前道路的路線，正常 CAN、已啟用橫向控制、速度介於 0.3 與 8 m/s、位於下一個一般左／右轉之前的短距離範圍，才接受新的方向盤確認。相同路線步驟只使用一次，最長 8 秒；MADS、煞車、油門、取消鍵、反向操作、盲點、EPS 故障、GPS 或路線失效等條件會阻止或終止意圖。匝道、迴轉、圓環與自動變換車道不會觸發本功能。

GPS 仍須 `hasFix`、資料新鮮度不超過 2.5 秒、水平精度大於 0 且不超過 20 公尺。補上 qcomgpsd 原先未填入的水平誤差：取 modem 所報誤差橢圓的較大軸（公尺），只有可靠度為 3／4、信賴值至少 68% 且數值合理時填入；不把 HDOP/VDOP 當成公尺，也不把缺失精度視為可靠定位。此修正無法補回舊行車紀錄沒有記錄的精度。

切換來源、目的地、語系或伺服器會使舊路線失效；過期的非同步結果會被丟棄。查詢間隔至少 2 秒，錯誤後退避重試，網路請求在獨立工作執行緒中執行。路線失配或資料過期時不提供有效轉彎意圖。

## 驗證

```sh
python -m unittest discover -s openpilot/sunnypilot/navd/tests -v
```

測試使用合成路線，不上傳行車紀錄或座標。涵蓋無權杖 OSRM 查詢、來源切換與過期結果、無效伺服器／回應、GPS 精度門檻、確認後的轉彎及取消，以及既有模型輸入契約。UI 開發方式見 [網頁預覽說明](../tools/ui_preview/README.md)。
